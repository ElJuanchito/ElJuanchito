## 🚀 About Me

I am a **Backend Engineer** focused on designing scalable, maintainable, and high-performance server-side architectures. With solid foundations in computer science, concurrent programming, and competitive problem solving (ICPC), I specialize in:

- **Distributed Systems & Microservices**: Building performant, decoupled services and API gateways using **Go** and **Java (Spring Boot 3)**.
- **Data Modeling & Storage**: Designing resilient relational schemas and optimized querying with **PostgreSQL** (PL/pgSQL, GORM, JPA) and NoSQL persistence with **MongoDB**.
- **Clean Architecture & Best Practices**: Applying Domain-Driven Design (DDD), Hexagonal Architecture, Container-Presentational patterns, and automated testing pipelines.
